# RE-VOLVE Machine Learning Module

## 1. Overview
This module provides a genuine, lightweight machine learning classification model for the **RE-VOLVE: Vehicle Retirement & Environmental Intelligence System**.

It uses **Scikit-learn**'s `RandomForestClassifier` with an end-to-end preprocessing pipeline (`StandardScaler`, `SimpleImputer`, `OneHotEncoder`) to predict the **inspection-priority category** of vehicles:
- `High priority`
- `Elevated priority`
- `Moderate priority`
- `Lower priority`

---

## 2. Model Architecture & Pipeline
- **Algorithm:** `RandomForestClassifier` (100 estimators, max depth 12, balanced class weights, fixed random seed 42)
- **Features Used:**
  - *Numerical (6):* `registration_year`, `annual_distance_km`, `historical_puc_failures`, `measured_co_percent`, `measured_hc_ppm`, `measured_smoke_opacity`
  - *Categorical (6):* `vehicle_category`, `fuel_type`, `emission_standard`, `puc_status`, `fitness_status`, `state`
- **Target Leakage Prevention:**
  Excluded target score (`inspection_priority_score`), rule factors (`contributing_factors`), action strings (`recommended_next_step`), and internal IDs.
- **Preprocessing Pipeline:**
  - Numerical: Median imputation + Standard scaling
  - Categorical: Constant imputation ("Unknown") + One-hot encoding (`handle_unknown='ignore'`)
- **Evaluation Split:** 80% Train (880 samples), 20% Test (220 samples), stratified on target classes.

---

## 3. Evaluation Metrics (Test Set: 220 samples)
- **Accuracy:** 85.00%
- **Macro F1-Score:** 0.8555
- **Weighted F1-Score:** 0.8499
- **Per-Class Breakdown:**
  - **High priority:** Precision: 0.86 | Recall: 0.92 | F1: 0.89 (13 test samples)
  - **Elevated priority:** Precision: 0.87 | Recall: 0.86 | F1: 0.86 (76 test samples)
  - **Moderate priority:** Precision: 0.84 | Recall: 0.84 | F1: 0.84 (96 test samples)
  - **Lower priority:** Precision: 0.83 | Recall: 0.83 | F1: 0.83 (35 test samples)

## 4. Honest Disclosure & Limitations
1. **Rule-Imitation Prototype:** The target labels (`priority_category`) in this dataset were generated by RE-VOLVE's deterministic scoring engine (`src/lib/scoring.ts`).
2. **Not Empirical Emissions:** The model does NOT predict real-world grams of tailpipe emissions or ambient city air quality. High test accuracy reflects the model's ability to imitate multi-factor regulatory criteria from observed attributes.
3. **Decision Support Only:** Predictions are advisory inputs for inspection prioritisation, not proof that a vehicle should be retired.

## 5. Setup & Execution Commands (PowerShell)

### 1. Create Environment & Install Dependencies
```powershell
python -m venv ml\.venv
.\ml\.venv\Scripts\pip.exe install -r ml\requirements.txt
```

### 2. Train and Evaluate the Model
```powershell
.\ml\.venv\Scripts\python.exe ml\train.py
```

### 3. Run Standalone CLI Prediction
```powershell
.\ml\.venv\Scripts\python.exe ml\predict.py
```

### 4. Start the FastAPI Inference Service (Port 8000)
```powershell
.\ml\.venv\Scripts\python.exe -m uvicorn ml.service:app --host 127.0.0.1 --port 8000
```
