# Three-minute demo script

Dataset: labelled synthetic demo fleet (1,100 rows). No government login required.

1. **Problem (20s)** — Open `/`. “Age is not a pollution measurement. Two 15-year-old vehicles can be entirely different cases.” Click **Explore Vehicle Intelligence**.

2. **Dashboard (40s)** — Point at the synthetic banner. Show total, flagged-for-review, PUC failed. Filter **Fuel = Diesel**, then **Bharat Stage = BS-III**. Charts and the table recompute. Open a high-score `SYN-` row.

3. **Assessment (40s)** — Load **Failed diesel HCV**. Score ~high. Walk the factor bars: failed test is evidence; age is a weak prior. Contrast with **New electric two-wheeler**. Note the recommendation is a next step, not “scrap it”.

4. **Simulator (50s)** — Compare top 10% inspection vs expired-fitness vs replacement-first BS-I/II. Show priority-point coverage and the limitations list. Say out loud: “We do not convert this score into kilograms of PM2.5.”

5. **Close (20s)** — Methodology page: VAHAN is cited as a dashboard, not an API. Central idea: *identify which vehicle populations deserve attention first, using available evidence rather than assumptions.*
